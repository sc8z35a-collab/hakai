# FRACTURE — Destruction Sandbox

## プロジェクト概要
提供写真の青いガラス張り高層ビルをモチーフにした、10階建てビルのブラウザ向け3D破壊サンドボックスです。白いグリッド空間に建物だけを置き、内装、局所破壊、剛体衝突、自由飛行に集中しています。HTML / CSS / JavaScriptで動作し、バックエンド、ビルド作業、アカウント、APIキーは不要です。

**重要：** Cannon-esによる剛体物理を使いますが、構造損傷と支持喪失の判定はゲーム用の近似モデルです。工学的な建築安全性評価、爆発解析、有限要素法シミュレーションではありません。

## 完成済み機能
- Three.js製の3D空間、影、反射環境、角を丸めたカーテンウォール、独立したガラス・アルミ部材。
- 10階、階高4.2m、約43m級の建物と屋上設備。
- 床、支柱、壁、家具、外装、地表タイルを含む初期3,463個の独立部材。
- 内装：机、椅子、モニター、キーボード、ソファ、植木、テーブル、書籍入り書棚、カフェ設備、会議室、エレベーター扉、階表示、階段、照明など。
- 各階の用途：
  1. RECEPTION / ロビー
  2. COMMONS / カフェ
  3. WORKSPACE / コワーキング
  4. OPEN OFFICE / オフィス
  5. CONFERENCE / 会議室
  6. DESIGN STUDIO / スタジオ
  7. LIBRARY / ライブラリー
  8. EXECUTIVE / 役員フロア
  9. SKY LOUNGE / ラウンジ
  10. WINTER GARDEN / スカイガーデン
- 自由飛行、スマホ横画面用レイアウト、マルチタッチ移動スティック、スワイプ視点、上下移動ボタン。
- 当たり判定ON/OFF。ONでは球形の飛行プレイヤーが壁・床・瓦礫と衝突。OFFではすり抜け可能。
- 遠隔C4、より強力な遠隔爆薬3種（BREACH / SEISMIC / CATACLYSM）、衝突時に爆発する飛翔ミサイル。
- 照準で爆薬を設置、設置した部材への追従、全爆薬の一括遠隔起爆。
- 爆心からの距離に応じた部材損傷、床の局所的な欠落、ガラス破片、割れた支柱、飛散する家具。
- 重力、質量、摩擦、反発、角速度、衝突を持つ瓦礫。飛散破片は**シミュレーション時間で5秒**後に描画と物理ボディを削除。
- 支柱の残存強度と床の欠損率による支持喪失判定、上階への連鎖、階層単位の剛体落下・傾斜。
- 爆発後の揺れ、残存支柱位置に応じた初期傾斜方向、動的階層への爆風インパルス。
- ビル付近40m四方の地表タイルも破壊可能。周囲は白いグリッドと霧のみ。
- 閃光、リング、粉塵、カメラシェイク、任意の効果音（Web Audio合成、初期OFF）。
- 0.2倍スロー、一時停止、確認付きリセット、構造健全度、各階の支柱状態、破片数、設置爆薬数、FPS表示。
- 内装へ移動 / 次の階へ移動 / 外観へ戻る、操作説明、全画面API（対応ブラウザのみ）。

## 操作
### スマートフォン（横向き推奨）
1. 端末を横向きにする。縦向きでも「このまま続ける」で遊べます。
2. 左スティックで移動、ゲーム画面の右側をスワイプして視点変更。
3. ↑ / ↓で上昇・下降。
4. 装備を選び、照準を部材へ向け、「設置する」→「起爆」。ミサイルは「発射する」で発射。
5. 「階移動」で次の内装階へ。「外観」で初期位置へ戻る。
6. 当たり判定OFFで建物を通り抜けられます。

## 物理モデルと制限
- **静的な階層 + 動的な破片 + 支持を失った動的階層**のハイブリッドです。初期の各階は複合衝突形状を持つ静的ボディ。損傷で支持を失うと動的剛体へ移行します。
- 支持強度が57%未満、または床部材の残存率が50%未満になると上階への落下を予約します。これはプレイ用の閾値です。
- 床は約3.56m × 3.46m、地表は4m × 4mの部材分割。任意形状のリアルタイム切削やFEMではありません。
- ガラスの表示は三角形、衝突形状は薄い箱。家具の細部は描画し、衝突は家具単位の箱で近似します。
- 全体の揺れには描画用振動も併用。質量・慣性は物理エンジンで計算し、初期傾斜方向は残存支柱位置から近似します。重心と支持点の厳密な構造解析ではありません。
- 落下する階層も瓦礫扱いで、動的になってから5シミュレーション秒後に消えます。衝突で新しく発生した破片には、新たに5秒の寿命が付きます。
- スロー0.2倍では破片寿命は実時間で約25秒、一時停止中は寿命も停止。処理落ち時はシミュレーション時間が遅くなります。
- 爆薬の数値は架空のゲームパラメーターで、実在の性能や工学的な破壊評価を表しません。
- 地表の動的破壊はビル付近40m四方のみ。下には浅い衝突地盤があり、無限には掘削できません。
- エレベーターや階段は内装です。可動エレベーター、通常の徒歩・階段昇降システムは未実装。移動は飛行が前提です。
- WebGLが必要です。全画面APIや画面方向ロックが非対応の場合は、手動で端末を横向きにしてください。
- 大規模崩壊時には多数の複合剛体と衝突が発生します。端末固有のFPSや60fps動作は保証しません。

## 機能エントリーURI
| パス | 内容 |
|---|---|
| `/` または `/index.html` | 通常の外観から開始 |
| `/index.html?view=interior&floor=1` | 1階内装から開始 |
| `/index.html?view=interior&floor=4` | 4階オフィスから開始 |
| `/index.html?view=interior&floor=N` | `N=1〜10`（範囲外は補正） |
| `/index.html?portrait=continue` | 縦向き案内を省略 |
| `/index.html?test=smoke` | 実シミュレーションとUIの自動診断。テスト中に爆破し、最後に再構築 |
| `/tests/smoke.html` | 自動診断入口。コンソールにPASS / FAILを出力 |
| `/tests/interior.html` | 実際の4F内装URIへリダイレクトする描画確認入口 |
| `/tests/mobile.html` | 実際の縦画面ゲームURIへリダイレクトする描画確認入口 |
| `/tests/damage.html` | `?test=visual-damage`へ遷移。爆破直後の実シーンを停止して描画確認 |

通常アクセスでは自動爆破や自動移動は行いません。

## データモデル・保存・サービス
- `floor`：階番号、描画グループ、複合剛体、部材リスト、動的化予約、寿命。
- `entity`：種類、寸法、質量、HP、所属階、メッシュ、衝突形状、生存状態。
- `debris`：メッシュ、個別剛体、削除時刻。
- `charge`：装備タイプ、配置メッシュ、追従部材。
- `missile`：位置、進行方向、寿命。
- 全状態は現在のタブのメモリのみ。リロードまたはリセットで初期化。
- Table API / D1 / R2 / localStorage / サーバー保存は未使用。個人情報入力、解析用送信、認証はありません。
- 3Dライブラリはローカル配信。Google Fontsのみ外部アクセスし、失敗時はシステムフォントへフォールバック。
- 外部LLMや音声素材APIへの依存はありません。

## 検証結果
- 実ブラウザで起動を確認。JavaScript実行エラーなし。
- デスクトップで外観、4階内装、爆破直後の局所欠損・飛散破片をスクリーンショットで確認。
- `viewport=mobile`（390×844）で縦向き案内と実操作画面を確認。ジョイスティック、上下移動、5種の装備、設置・起爆、階移動にクリッピングなし。
- 最終スモークテスト：**PASS**。実際のCannon / ThreeシーンとUIボタンを使い、以下を検証：
  - 初期状態、照準、C4設置・起爆ボタン。
  - 破片の衝突形状と5秒寿命。
  - 当たり判定、スロー、一時停止ボタン。
  - 全10階の内装への移動。
  - ヘルプ・リセットダイアログ。
  - ミサイル衝突と遠隔爆薬の威力順序。
  - 支柱破壊による階層落下、物理座標の有限性、破片削除、再構築。
- ヘッドレス環境はソフトウェアWebGLのためGPU警告が出ます。実端末の性能測定結果ではありません。
- **未検証：実スマホ横向きでの長時間・多指操作、各端末のFPS / 温度、iOS / Android各機種での全画面挙動。** 横向きCSSとタッチ操作は実装済みですが、提供ツールのスマホキャプチャは縦向き固定です。
